# 广告电商工作台开发切片

新画布放在 `infinite-canvas/`，旧原型的 `app/web/` 保留原状。底座来自用户提供的 `infinite-canvas-0.19.0` 源码目录；上游版本 `v0.19.0` 对应提交 `e856c878e0a34651bb828e28f0af20d71016a7d4`，许可证为 MIT，已保留版权文件与页面原作者信息。

首次运行，在 `infinite-canvas/web` 执行 `npm install --legacy-peer-deps`。之后双击仓库根目录的 `启动广告电商工作台.bat`，打开 `http://127.0.0.1:3000/canvas`，创建画布后点击右上角“广告电商工作台”。本地伴随服务监听 `127.0.0.1:8766`，读取仓库根目录现有 `.env` 中的 DeepSeek 和 SeeAny 密钥，不回传密钥。旧原型继续使用它原有的启动脚本和端口。

当前切片支持本机商品项目、来源文件、事实状态、不可覆盖简报和母版版本、画布连线输入查看、DeepSeek 创作聊天、SeeAny 三视图候选与画布单张试图提交及状态同步。每组的正面、侧面、背面分别提交，最多两组；只允许同组的三张生成候选成为母版。画布试图读取所选配置节点的实际提示词和连线参考图，提交前展示输入快照，并能并排对照原图与生成图。费用未知时展示未知；连线操作不调用供应商；提交必须带当前输入指纹和幂等键。SeeAny 完成的图下载回本机，供应商临时 URL 不作为项目永久资产。

当前尚未接通完整广告流程：套图策划与交付、Flova 单镜参考图上传、编辑与导出包，以及真实商品验收。Flova 单镜任务在能力核验前会返回明确的手动路径。旧原型的预算门槛没有带入新服务。

前端画布项目仍由底座的浏览器 IndexedDB 管理；商品资料与任务状态保存在 `data/commerce-studio`。二者以浏览器本地映射关联，完整跨存储备份与恢复尚待实现。请在手工测试时使用非敏感试验资料。
