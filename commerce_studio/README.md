# 广告电商工作台开发切片

新画布放在 `infinite-canvas/`，旧原型的 `app/web/` 保留原状。底座来自用户提供的 `infinite-canvas-0.19.0` 源码目录；上游版本 `v0.19.0` 对应提交 `e856c878e0a34651bb828e28f0af20d71016a7d4`，许可证为 MIT，已保留版权文件与页面原作者信息。

首次运行，在 `infinite-canvas/web` 执行 `npm install --legacy-peer-deps`。之后双击仓库根目录的 `启动广告电商工作台.bat`，打开 `http://127.0.0.1:3000/canvas`，创建画布后点击右上角“广告电商工作台”。本地伴随服务监听 `127.0.0.1:8766`，读取仓库根目录现有 `.env` 中的 DeepSeek 和 SeeAny 密钥，不回传密钥。旧原型继续使用它原有的启动脚本和端口。

当前切片支持本机商品项目、来源文件、事实状态、不可覆盖简报和母版版本、画布连线输入查看、DeepSeek 文本资料候选事实提取、创作聊天与三种广告方向、脚本及分镜人工审批、SeeAny 三视图候选与画布单张试图提交及状态同步。模型提取事实始终先标“待核实”，需人工逐项审核；PDF、DOCX 和图片仍标为需人工查看。每组的正面、侧面、背面分别提交，最多两组；只允许同组且依据当前简报的三张生成候选成为母版。画布试图读取所选配置节点的实际提示词和连线参考图，提交前展示输入快照，并能并排对照原图与生成图。费用未知时展示未知；连线操作不调用供应商；提交必须带当前输入指纹和幂等键。SeeAny 完成的图下载回本机，供应商临时 URL 不作为项目永久资产。

已批准完整分镜后可新建或关联 Flova 项目，查看本次输入和未知费用，再由用户明确提交一次聚合运行。伴随服务上传确认的事实、脚本、分镜及三视图，保存任务状态并提供远端恢复入口。当前环境的代理拒绝 Flova 服务请求，此链路尚未经过真实运行验证；CLI 是否按镜头精确执行、回传费用及镜头素材仍待核实，精剪可从项目链接打开。

套图可从本地六图结构起步，或由 SeeAny 生成待审核的策划；逐张编辑图片类型、提示词、比例及可编辑标题/副标题，保存新版本并批准后逐张显式提交正式出图。同步远端结果、核对真实性并采用后，可下载套图 PNG、带独立文字层的 SVG、脚本及来源清单。当前无法连接 SeeAny 在线文档和接口，策划与正式出图参数沿用仓库原型的已接入形状，真实账户运行及拼多多后台上传规格仍待验证。套图导出已由本地测试覆盖，实际排版需用真实商品人工验收。

每个任务保存独立费用流水，记录供应商、阶段、草稿／正式用途、未知预估、实际结算状态和币种。当前供应商接入尚未返回可信的实付回执，因此界面将这些任务列为待结算，不把未知值或本地估算伪装成已花费。

提示词以产品特征、场景、构图、光线和禁止变化项分别保存不可覆盖版本。用户可选择本轮允许修改的字段，DeepSeek 返回 2～3 个候选；服务仅合并这些字段并保留其他字段。每个候选可引用当前已批准母版单独生成一张低成本模式试图，经原图对照和真实性审核后采用。保存的完整提示词可加入底座画布文本节点，继续使用其连线输入。

侧栏“下载完整项目备份”将当前浏览器画布、画布媒体、原始资料、版本、任务、审核与费用记录一起打包。画布列表的“导入”可识别该组合 ZIP，创建新的画布和本地商品项目，并恢复二者关联；运行中的远端任务在恢复后必须重新核对。该往返已做结构与文件校验测试，浏览器中的真实大文件备份仍需手工验收。

当前尚未接通完整广告流程：Flova 单镜控制、收尾编辑与视频导出，以及真实商品验收。画布单镜视频节点仍返回明确的手动路径。旧原型的预算门槛没有带入新服务。

前端画布项目仍由底座的浏览器 IndexedDB 管理；商品资料与任务状态保存在 `data/commerce-studio`。二者以浏览器本地映射关联，并可通过组合 ZIP 搬迁。备份不包含 `.env` 密钥；请在手工测试时使用非敏感试验资料。
