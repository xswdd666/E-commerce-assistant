# 广告电商工作台开发切片

新画布放在 `infinite-canvas/`，旧原型的 `app/web/` 保留原状。底座已与 GitHub `basketikun/infinite-canvas` 的 `main` 提交 `dab19adc0847e32e39b7fc8ff90cb392561fb826` 对齐：它与用户先前提供的 `v0.19.0` 源码（提交 `e856c878e0a34651bb828e28f0af20d71016a7d4`）相比，程序文件内容相同，差异仅为 README 和两张赞助商图片。已采用 GitHub 版本的这些差异；许可证为 MIT，保留版权文件与页面原作者信息。下载快照保存在 `data/upstream-downloads/`，并未覆盖本仓库的电商扩展代码。

双击仓库根目录的 `启动广告电商工作台.bat`，打开 `http://127.0.0.1:3000/canvas`，创建画布后点击右上角“广告电商工作台”。首次启动如缺少依赖，会自动安装画布 npm 包和本地图片／文档解析包；这一步需要能访问 npm 与 PyPI，安装失败会在窗口显示原因。后续启动使用已有依赖，不再重复安装。本地伴随服务监听 `127.0.0.1:8766`，读取仓库根目录现有 `.env` 中的 DeepSeek 和 SeeAny 密钥，不回传密钥。启动器仅在发现当前环境注入的无效 `127.0.0.1:9` 代理时清除它；正常代理设置保留。旧原型继续使用它原有的启动脚本和端口。

当前切片支持本机商品项目、来源文件、事实状态、不可覆盖简报和母版版本、画布连线输入查看、DeepSeek 文本、PDF/DOCX 正文及原始实拍候选事实提取、创作聊天与三种广告方向、脚本及分镜人工审批、SeeAny 三视图候选与画布单张试图提交及状态同步。模型提取事实始终先标“待核实”，需人工逐项审核；扫描版 PDF、加密或损坏文档标为“需人工查看”。原始文件可下载回查，提取的正文可在侧栏展开。DeepSeek 图文观察可对照原始实拍和 SeeAny 候选图逐项描述颜色、形状、结构、Logo、文字、配件、场景与卖点，人工纠正单独留痕，不自动成为产品事实或图片审批。每组的正面、侧面、背面分别提交，最多两组；只允许同组且依据当前简报的三张生成候选成为母版。画布试图读取所选配置节点的实际提示词和连线参考图，提交前展示输入快照，并能并排对照原图与生成图。费用未知时展示未知；连线操作不调用供应商；提交必须带当前输入指纹和幂等键。SeeAny 完成的图下载回本机，供应商临时 URL 不作为项目永久资产。

母版审核可逐行登记缺少原图证据的结构。每项必须指定原始实拍才可标为已核实，核实会生成不可覆盖的母版新版本，并要求下游广告方向、脚本和分镜重新审核。分镜需声明涉及的推断结构；声明未核实项的分镜不能获批，Flova 提交时再次核对。创作者仍须人工检查脚本、字幕和画面描述是否漏标了相关细节。

已批准完整分镜后可新建或关联 Flova 项目，查看本次输入和未知费用，再由用户明确提交一次聚合运行。也可逐镜提交：每次仅上传该镜头的分镜和参考母版，Flova 返回后须在远端核对并手动批准，才能提交下一镜；失败镜头可重新提交。全部镜头批准后，还须在 Flova 核对完整时间线并批准，才能申请最终导出。整片与逐镜路径不能在同一分镜版本中混用；版本变化会阻止旧任务导出。Flova CLI 只有聚合 `run`，逐镜限制靠提交内容与创作指令实现，因此实际单镜控制精度、费用及镜头素材仍须用真实商品验证，精剪可从项目链接打开。

Flova 运行终态按成功、失败和待用户确认区分。用户在 Flova 核对镜头后可批准本轮视频；工作台再检查导出条件，明确提交 Flova 成片导出，下载 MP4 到本机项目目录，供界面下载并纳入完整备份。镜头资源列表可单个显式下载视频，作为本机收尾片段并进入备份。已下载的镜头、原片和收尾成片还可显式复制到浏览器本地画布视频节点；节点保存本机商品项目和交付物 ID，组合备份恢复时重映射项目 ID。视频复制会占用浏览器本地存储。导出和资源结构仅有本地模拟验证，实际资源字段仍待试点项目核对。

本地收尾可对已下载的 Flova 成片添加多个片段，调整顺序、头尾、0.5～2 倍速度及字幕，并按片段时长预览总长。保存为不可覆盖编辑版本后使用 FFmpeg 渲染 720×1280 MP4；音频速度用 `atempo` 保持音高，原始 Flova 文件不改写。合成结果可在页面预览、下载，并进入项目备份。开发机使用真实 FFmpeg 对短测试视频完成了裁剪、变速、字幕及输出时长检查；实际小家电成片仍待人工审看。

交付区可选择 Flova 原片或本地收尾成片，与已采用的套图一起打成一个 ZIP。包内有 MP4、逐张 PNG/SVG、确认脚本与分镜、采用提示词及来源清单。必须先逐张采用套图、确认脚本和分镜；实际拼多多后台文件限制仍需人工核对。

套图可从本地六图结构起步，或由 SeeAny 生成待审核的策划；逐张编辑图片类型、提示词、比例及可编辑标题/副标题，保存新版本并批准后逐张显式提交正式出图。同步远端结果、核对真实性并采用后，可下载套图 PNG、带独立文字层的 SVG、脚本及来源清单。SeeAny 在线文档和账户只读接口已验证，策划与单张出图参数已对照当前文档；真实付费运行及拼多多后台上传规格仍待验证。官方文档目前将套图策划标价为每次 0.10 元，失败退回，界面将其列为预估而非实付。套图导出已由本地测试覆盖，实际排版需用真实商品人工验收。

每个任务保存独立费用流水，记录供应商、阶段、节点、草稿／正式用途、未知预估、实际结算状态和币种。当前供应商接入尚未返回可信的实付回执，因此界面将这些任务列为待结算，不把未知值或本地估算伪装成已花费。用户核对供应商账单后可登记原始金额、单位和账单出处；更正会保留前次金额与出处。项目总览可按供应商、阶段、节点、用途或提交日期查看费用；选中画布节点可看该节点累计实付与待结算笔数。用户可填写按原始单位计的项目成本目标，超出时只提示，不阻断任务。预估和实付分开，积分与货币不会混加。

提示词以产品特征、场景、构图、光线和禁止变化项分别保存不可覆盖版本。用户可选择本轮允许修改的字段，DeepSeek 返回 2～3 个候选；服务仅合并这些字段并保留其他字段。每个候选可引用当前已批准母版单独生成一张低成本模式试图，经原图对照和真实性审核后采用。保存的完整提示词可加入底座画布文本节点，继续使用其连线输入。

已有 GPT 图片可导入当前提示词上下文；导入时记录实际 GPT 提示词及所用母版参考图。图片先进入候选列表，经过原图对照与人工审核后才能采用。导入图也可交给 DeepSeek 做图文观察；交付包记录实际生成提示词、参考图及来源，不把上下文版本误写成 GPT 实际输入。

侧栏“下载完整项目备份”将当前浏览器画布、画布媒体、原始资料、版本、任务、审核与费用记录一起打包。画布列表的“导入”可识别该组合 ZIP，创建新的画布和本地商品项目，并恢复二者关联；运行中的远端任务在恢复后必须重新核对。本机服务重启时也会把上次未结束的任务标为“待核对”，不会自动补发。没有可信远端 ID 的任务，须先在供应商后台确认不存在，再记录核对依据并手动标记失败。该往返已做结构与文件校验测试，浏览器中的真实大文件备份仍需手工验收。

空白画布的工作台可选择旧原型 SQLite 项目进行一次只读导入。资料文件经哈希校验后复制到新项目，旧事实与来源关系一并带入；旧母版、提示词、任务、费用和原始预算设置保存在可下载的历史 JSON 快照中，母版和成品仍需在新流程重新审核。旧数据库和文件不会改动，旧预算设置不会成为新工作台的执行门槛。

画布列表提供本机项目库搜索，可按项目名、素材文件名和提示词文本查询；旧项目导入的提示词历史也参与检索。有关联画布的结果可直接打开。

画布列表删除项目时会同时删除该画布最后关联的本机商品项目，包括来源文件和已下载 MP4；被其他画布共同引用的商品项目会保留。删除确认框会提示先备份，且不会替用户删除远端 Flova 工程。浏览器中未再引用的图片、音视频媒体由底座清理流程回收。

当前尚未完成完整广告流程的真实商品验收。Flova 逐镜提交和人工审核已接入，但单镜控制效果尚未实测；单个视频镜头资源可以显式下载，实际 Flova 项目资源结构仍待验证。Jev 旁路判断已按 [TypeSafe 官方 System One 协议](https://api.typesafe.ai/openapi.json)接入三个广告方向的只读选择：须在本机 `.env` 配置 `TYPESAFE_API_KEY` 并显式确认提交，返回的选择、概率与人工最终选择分别留痕，Jev 不会批准方向或素材。当前没有 Jev 密钥，真实返回和计费尚未验证。画布单镜视频节点仍返回明确的手动路径。旧原型的预算门槛没有带入新服务。

前端画布项目仍由底座的浏览器 IndexedDB 管理；商品资料与任务状态保存在 `data/commerce-studio`。二者以浏览器本地映射关联，并可通过组合 ZIP 搬迁。备份不包含 `.env` 密钥；请在手工测试时使用非敏感试验资料。
